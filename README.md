## Deployment

### Podman Compose

```yaml
services:
  memos:
    image: "ghcr.io/daemonless/memos:latest"
    container_name: memos
    environment:
      - PUID=1000  # User ID for the application process
      - PGID=1000  # Group ID for the application process
      - TZ=UTC  # Timezone for the container
      # - MEMOS_INSTANCE_URL=  # Canonical external URL of the Memos instance
      # - MEMOS_DRIVER=  # Database driver (sqlite, postgres, or mysql; defaults to sqlite)
      # - MEMOS_DSN=  # Database connection string when using postgres or mysql
      # - MEMOS_DSN_FILE=  # Path to a file containing MEMOS_DSN
      # - MEMOS_LOG_LEVEL=  # Log verbosity level (debug, info, warn, error)
      # - MEMOS_DEMO=  # Seed the instance with demo content on first start
      # - MEMOS_TRUSTED_PROXIES=  # Comma-separated CIDRs, IPs, private, or none for forwarding headers
    volumes:
      - "/containers/memos:/config"
    ports:
      - "5230:5230"
    # always (not unless-stopped) so FreeBSD's podman rc.d auto-starts it at boot
    restart: always
```

Save as `compose.yaml`, then run `podman-compose up -d`.

### AppJail Director

**appjail-director.yml**:

```yaml
# appjail-director.yml

options:
  - virtualnet: ':<random> default'
  - nat:
services:
  memos:
    name: memos
    options:
      - container: 'args:--pull'
      - expose: '5230:5230 proto:tcp'
    oci:
      user: root
      environment:
        - PUID: !ENV '${PUID}'
        - PGID: !ENV '${PGID}'
        - TZ: !ENV '${TZ}'
    volumes:
      - memos: /config
volumes:
  memos:
    device: '/containers/memos'
```

**Makejail**:

```
# Makejail

ARG tag=latest

OPTION container=boot
OPTION overwrite=force
OPTION from=ghcr.io/daemonless/memos:${tag}
```

Save the files above, then run `appjail-director up`.


> [!WARNING]
> Exposing ports in AppJail means that your service can be reached from remote hosts. If that is not your intention, do not expose the ports and communicate with the service using the jail's IPv4 address or hostname assigned by the virtual network.
>
> To avoid exposing ports, just remove the `expose` option in your `appjail-director.yml` or from your command-line arguments.

## First start and data

Open `http://<host>:5230` to create the initial host account. By default
Memos uses an embedded SQLite database stored in `/config` alongside any
uploaded attachments.

## External database

To use PostgreSQL or MySQL instead of SQLite, set `MEMOS_DRIVER` to
`postgres` or `mysql` and pass the connection string via `MEMOS_DSN` (or
`MEMOS_DSN_FILE`).

## CLI subcommands

Run Memos CLI commands as `bsd` in `/config`, for example:

```sh
podman exec memos memos version
```
